# Third-party components and publication scope

The root MIT license applies to original project code. It does not replace upstream terms or grant rights to datasets, checkpoints or the manuscript. Existing source headers are retained.

| Component | Location / role | Terms and source-export handling |
|---|---|---|
| BEVHeight | `code/trajectory/` detector foundation and local modifications | Upstream MIT; copy in `code/trajectory/LICENSE.BEVHeight`. [Upstream](https://github.com/ADLab-AutoDrive/BEVHeight) |
| AnyCalib | `code/trajectory/third_party/AnyCalib/` | Apache-2.0, retained local LICENSE. Source module included; weights and caches omitted. [Upstream](https://github.com/javrtg/AnyCalib) |
| AB3DMOT | Local `code/trajectory/third_party/AB3DMOT/` dependency | Supplied academic/noncommercial license restricts redistribution. Entire dependency omitted from Git/source ZIP; obtain directly under its terms. Integrations are not a grant of rights to the upstream software. [License](https://github.com/xinshuoweng/AB3DMOT/blob/master/LICENSE) |
| BEVDepth / DAIR-V2X lineage | Acknowledged by the upstream detector; retained source notices | Consult the upstream projects and preserved file headers for component-specific terms. [BEVDepth](https://github.com/Megvii-BaseDetection/BEVDepth), [DAIR-V2X](https://github.com/AIR-THU/DAIR-V2X) |
| PyTorch / OpenMMLab / scientific Python | Installed dependencies | Installed separately; compiled environments are not redistributed. Preserve each dependency's license. |

The historical trajectory/classifier source snapshots include modifications made before this repository cleanup. Their existing provenance and attribution remain in place. This cleanup does not assert that every inherited file was newly authored by the project.

Field video, GPS, annotation revisions, public training payloads, pretrained weights and runtime copies are excluded from the source export. The review application's demonstration imagery is synthetic SVG content generated by the project. The manuscript, its Elsevier template and generated publication figures are maintained separately and are not included in this code repository.
